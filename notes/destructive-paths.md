# Destructive-path inventory

Ceph v19.2.3, commit `c92aebb279828e9c3c1f5d24613efca272649e62`. Paths are relative to `/data/ceph/src`. Started 2026-09-25 (Phase 3), aiming for completeness over depth.

"v1" means the Phase 4 prototype: object deletes only, retained at acting-set rank 1, hooked in `ReplicatedBackend::do_repop` (see `design-note.md` §3).
